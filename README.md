# AiMS Website

Static, mobile-responsive AiMS website source, intended for importing into Votel and publishing at getaims.co after review.

## Files
- `index.html`: updated homepage with the Parent Journey Enrollment System, school outcomes, year-long nurturing, AI advertising and offer.
- `parent-journey.html`: training landing page, currently with a clear video placeholder.

## Run locally
No build step is required. Serve the folder with any static server, for example `python3 -m http.server 8000`, then visit http://localhost:8000.

## Deployment
- **Framework:** Static HTML
- **Build command:** none
- **Output directory:** repository root
- **Entry point:** `index.html`
- In Votel, connect this GitHub repository, configure the site as static, and point your production domain only after approval.
- The reference preview at aims-results-homepage-concept.losched16.chatgpt.site was published through a separate site service. This repository contains a reconstructed, updated copy based on the latest approved messaging, not a byte-for-byte export of that service.
